# SurroSim v0.3 — Simulation dataset factory

v0.3 turns the validated v0.2 FEA engine into a reproducible dataset
factory: design sampling, parallel solver execution, failure handling,
label gating and provenance. No ML model is trained here.

## Dataset versions

| dataset | cases | splits | failures | solver | location |
| --- | --- | --- | --- | --- | --- |
| `v1` | 644 | train 392 / val 84 / test 84 / challenge 84 | 0 | CalculiX 2.23 | `data/dataset_v1/` |

Artifacts committed to the repository: the design table
(`data/designs_v1.csv`), the scalar dataset (`dataset.csv`), the manifest
(`manifest.json`), the dataset card and `failures.csv`. Per-case artifacts
(mesh, deck, nodal fields) live under `data/runs/` and are intentionally not
committed (~4.7 GB); they are regenerable from the design table.

## Sampling

Sampling is defined by an explicit `DesignSpace` and drawn with scrambled
Sobol sequences (Latin hypercube selectable).

| factor | range |
| --- | --- |
| length | 100–160 mm |
| width | 30–60 mm |
| thickness | 4–10 mm |
| hole diameter / width | 0.20–0.45 |
| hole position / length | 0.35–0.65 |
| force (total, −Z) | 100–800 N |

Composition of the `v1` table (644 cases):

- **560 main cases** split 70/15/15 into train/val/test. 5% of main cases are
  sampled with `hole_diameter_mm = 0` and re-centred so the model sees both
  perforated and unperforated geometry.
- **72 challenge cases** drawn from the outer 10% band of every factor and
  held out of training (corner-of-design-space stress test).
- **12 explicit edge cases**: min/max combinations, thin + high force,
  slender, stubby, hole near clamp, hole near load, no-hole variants, and
  the nominal design.

## Execution

```bash
surrosim dataset sample --count 560 --challenge-count 72 --out data/designs_v1.csv
surrosim dataset run --designs data/designs_v1.csv --out data/runs --jobs 6 --ccx ccx
surrosim dataset build --designs data/designs_v1.csv --runs data/runs --out data/dataset_v1
```

- Cases run in parallel processes and are **resumable**: a successful case is
  reused unless `--force` is given.
- Transient CalculiX crashes (observed as a Windows access violation in
  ~3% of runs under heavy parallelism) are retried (`--retries`, default 1).
- After a successful solve, nodal fields are converted to a compact
  `fields.npz` (float32) and bulky solver artifacts (`.frd`, `.dat`, `.sta`,
  `.cvg`, `fields.csv`) are pruned.

Mesh policy for every dataset case is the validated production policy:
C3D10 tetrahedra, global size `min(3 mm, t/2)`, hole surface graded to
`min(0.6 × global, d/10)`.

## Label gating

A case enters `dataset.csv` only if **all** gates pass:

1. solver status is `SUCCESS`;
2. the distributed deck load matches the requested total force;
3. mesh node count is at least 500;
4. `fields.npz` exists;
5. max displacement and global max Von Mises are finite and positive;
6. ROI stress is finite and positive whenever defined.

Anything else is written to `failures.csv` with a machine-readable reason
(`SOLVER_FAILED`, `MISSING_RUN_JSON`, `FORCE_GATE`, `MESH_GATE`,
`OUTPUT_GATE`, ...) and never used as a label.

## Provenance

`manifest.json` records the dataset schema version, creation time, design
file and dataset SHA-256 hashes, split counts, mesh policy, solver versions,
total solver time, Python/platform, and the git commit plus dirty flag of
the repository at build time. `dataset_card.md` summarises ranges, target
statistics, policy, label caveats and excluded cases.

## Sanity evidence for `v1`

- All 644 cases passed the gates (0 failures).
- 33 unperforated cases: FEA/beam-theory tip displacement ratio 0.968–0.989,
  consistent with the clamped-face stiffening quantified in
  `reports/validation/beam/report.md`.
- Displacement labels span 0.045–27.7 mm; global Von Mises 12.5–2071 MPa
  (linear elastic, no yield check); ROI stress is defined for all 611
  perforated cases and equals the global maximum in the majority of them.

## Caveats

- Labels are linear-elastic FEA results, not a yield or failure assessment.
  Stresses above ~250 MPa (typical steel yield) are outside elastic validity
  for real design use and are only valid as simulation outputs.
- The challenge split is designed to probe extrapolation; it must never be
  used for model selection.
