# SurroSim v0.2 — FEA engine implementation status

v0.2 turns the v0.1 geometry foundation into an automated CalculiX static-structural pipeline. The current implementation is intentionally conservative: only ASCII Gmsh MSH 2.2, first-order tetrahedra (`C3D4`), linear elasticity and a static transverse load are accepted.

## Implemented

- Strict MSH 2.2 parser retaining `SOLID`, `FIXED_FACE` and `LOAD_FACE` physical groups.
- CalculiX `.inp` generation for C3D4 solids.
- Fixed boundary condition on `FIXED_FACE`.
- Requested force interpreted as a **total force** and distributed to `LOAD_FACE` nodes by tributary triangle area; mesh refinement therefore does not multiply the total force.
- CalculiX runner with machine-readable statuses: `SUCCESS`, `SOLVER_NOT_FOUND`, `SOLVER_TIMEOUT`, `SOLVER_FAILED`, `OUTPUT_MISSING`.
- ASCII FRD parser for the last `DISP` and `STRESS` nodal result blocks.
- Displacement magnitude and Von Mises calculation from `SXX,SYY,SZZ,SXY,SYZ,SZX`.
- Hole-region stress target (`1.5 × hole diameter`) with the first 10% of plate length excluded from ROI consideration.
- `run.json` per case and `fields.csv` containing nodal coordinates, displacement, stress components and Von Mises stress.
- No-hole geometry is allowed for the analytical cantilever validation milestone.

## Commands

```bash
surrosim generate --out outputs/plate_0001
surrosim prepare --out outputs/plate_0001
surrosim simulate --out outputs/plate_0001 --ccx ccx
surrosim simulate --hole-diameter-mm 0 --out outputs/beam_validation
```

`simulate` returns non-zero when the solver or result stage is unsuccessful and records the failure in `run.json`.

## Not yet release-complete

1. Run and visually inspect the generated Gmsh geometry/mesh on a machine with Gmsh installed.
2. Execute an actual CalculiX case and confirm the deck, FRD parser and load direction end to end.
3. Add C3D10/quadratic tetrahedral support or document C3D4 as the final v0.2 choice after convergence evidence.
4. Build the no-hole cantilever analytical-vs-FEA validation command/report.
5. Run and document the mesh-convergence study, then select the production mesh policy.
6. Verify the hole ROI against visual post-processing and document stress averaging limitations.

No FEA accuracy claim or ML label should be published until those checks are complete.
