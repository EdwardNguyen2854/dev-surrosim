# App fonts

Latin subsets vendored from the DesignKit font assets (`designkit/assets/fonts/`).

| File | Family | Axis / weight |
| --- | --- | --- |
| `manrope-latin.woff2` | Manrope | variable 200–800 |
| `fraunces-latin.woff2` | Fraunces | variable 300–700 |
| `ibm-plex-mono-400-latin.woff2` | IBM Plex Mono | 400 |
| `ibm-plex-mono-500-latin.woff2` | IBM Plex Mono | 500 |
| `ibm-plex-mono-600-latin.woff2` | IBM Plex Mono | 600 |

The subsets cover Basic Latin, Latin-1, and common punctuation.
