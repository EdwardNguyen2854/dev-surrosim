# Splash fonts

Latin subsets vendored for the desktop loading screen, copied from the web
app's `apps/web/src/assets/fonts/` (themselves from DesignKit's
`assets/fonts/`).

| File | Family | Axis / weight |
| --- | --- | --- |
| `manrope-latin.woff2` | Manrope | variable 200–800 |
| `fraunces-latin.woff2` | Fraunces | variable 300–700 |

The subsets cover Basic Latin, Latin-1, and common punctuation.
